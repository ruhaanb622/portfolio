# DNHS Underground Rap Club website

A responsive, dependency-free club landing page for the Del Norte Underground Rap Club.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/dnhs-ugrc/`.

## Content sources

Meeting time, room, club motto, leadership handles, Discord invite, and the Instagram follower snapshot are based on the public `@dnhs_ugrc` profile as viewed in August 2026.
